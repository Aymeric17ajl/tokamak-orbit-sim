\# 🌌 Tokamak Orbit Sim



\*\*An automated 3D scientific computing framework exploring magnetic confinement, charged-particle dynamics, and multi-scale numerical integration.\*\*



\---



\## 🔬 Project Overview \& Ambition



How can we simulate and guarantee the stability of a burning plasma inside a fusion reactor? 



This repository implements a rigorous numerical framework to track single charged-particle trajectories within a simplified toroidal magnetic field. By decoupling a custom-built, physics-blind \*\*4th-Order Runge-Kutta (RK4) solver\*\* from non-uniform helical field equations, this code bridges textbook plasma mechanics and robust software engineering.



Developed by an ambitious physics student eager to learn and grow, this project demonstrates computational discipline, automated verification, and a deep interest in computational plasma physics and thermonuclear fusion.



\---



\## 🎯 Core Project Objectives



\*   \*\*Generic Integration:\*\* Implement a reusable, modular RK4 ordinary differential equation (ODE) engine.

\*   \*\*Geometric Modelling:\*\* Simulate a non-uniform 3D helical magnetic field including toroidal and poloidal profiles.

\*   \*\*Dynamic Tracking:\*\* Solve the 6D coupled equations of motion derived from the Lorentz force.

\*   \*\*Automated Verification:\*\* Establish a strict, automated non-regression testing suite using `pytest`.

\*   \*\*Scientific Visualization:\*\* Generate clear, reproducible plots to investigate how initial conditions affect particle confinement.

\## ⚛️ Physical Model \& Governing Principles



\### The Lorentz Force Core

The spatial and velocity evolution of a non-relativistic charged particle (proton) is governed by the 3D \*\*Lorentz Force Law\*\*:

\*   \*Concept:\* Force = mass \* acceleration = charge \* (velocity vector x Magnetic Field vector)



The simulation groups these properties into a single \*\*6D State Vector\*\* combining 3D Cartesian positions (meters) and 3D velocity components (m/s). The magnetic field alters the particle's direction vector while strictly conserving its total kinetic energy and velocity magnitude.



\### Non-Uniform Helical Field Setup

To stabilize the plasma, the simulator overlays two perpendicular magnetic configurations:

1\.  \*\*Toroidal Field (B\_phi) - \*The Long Way Around\*:\*\* Generated by external coils, it follows a strict geometric 1/R decay law, growing weaker as the major radius R increases:

&#x20;   \*Formula: B\_phi = B0 \* R0 / R\*

2\.  \*\*Poloidal Field (B\_theta) - \*The Short Way Around\*:\*\* Generated by the current inside the plasma, it wraps vertically around the core and depends on the \*\*Safety Factor (q)\*\*:

&#x20;   \*Formula: B\_theta = (r / q) \* (B0 / R)\*



\---



\## 🧮 Numerical Method: Generic 4th-Order Runge-Kutta



The 6 coupled differential equations are integrated using a custom, explicit \*\*Fourth-Order Runge-Kutta (RK4)\*\* scheme. 



For any state vector equation \*dy/dt = f(t, y)\*, the step advances the state by taking a weighted average of four intermediate slopes evaluated across the time step intervals. 



Crucially, the integrator is written to be \*\*completely physics-blind\*\*. It knows nothing about tokamaks or protons, making it a highly modular math engine that can be reused for any other system of differential equations.

\## 🧪 Verification Framework \& Software Rigor



In scientific computing, \*\*we should never trust a simulation we haven't programmatically verified\*\*. This project implements an automated unit-testing pipeline using `pytest` to guarantee mathematical and physical soundness.



\### The 3 Safety Barriers of the Testing Suite (5 Passed):

\*   \*\*`test\_integrators.py`\*\*: Validates the mathematical precision of the generic RK4 algorithm against a reference exponential decay model whose exact analytical solution is known. This isolated test ensures the math engine is bug-free.

\*   \*\*`test\_fields.py`\*\*: Programmatically asserts the geometric integrity of the magnetic field model, verifying symmetries and the strict 1/R decay factor across multiple coordinates.

\*   \*\*`test\_particle.py`\*\*: Executes a quantitative physical benchmark. It runs a full micro-gyro-orbit simulation and compares the observed numerical displacement against the theoretical analytical \*\*Larmor Radius\*\* formula. It automatically accounts for the real-world 1/R magnetic gradient and enforces a rigid tolerance threshold.



To run the full suite of automated tests from the project root, execute:

```bash

python -m pytest

```
